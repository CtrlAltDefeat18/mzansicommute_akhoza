# Security Review

Read `docs/SECURITY.md`, `docs/API.md`, and `docs/DATABASE.md`.

Review:
- secret handling;
- authentication/authorisation boundaries;
- personal data;
- logging;
- input validation;
- abuse controls;
- dependency exposure;
- Cloudflare runtime assumptions;
- data-sharing pathways;
- founder-identifying content.

Distinguish confirmed vulnerabilities from hardening suggestions.
Do not weaken controls for convenience.
