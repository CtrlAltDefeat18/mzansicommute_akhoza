# Release Readiness

Audit the candidate release.

Check:
- install reproducibility;
- lint/type/test/build;
- environment variables;
- database migrations;
- Cloudflare configuration;
- indexing/robots intent;
- public claims;
- target/result labels;
- founder privacy;
- accessibility regressions;
- reduced-motion behaviour;
- secret leakage.

Do not deploy automatically.

Return blockers, warnings, and release notes.
