# Bootstrap / Repository Orientation

Read `AGENTS.md`, `docs/NORTH_STAR.md`, and `docs/CONSTITUTION.md` before doing anything.

Do not edit files yet.

Inspect the repository and report:
1. current architecture;
2. runtime/deployment model;
3. product state;
4. quality commands;
5. load-bearing files;
6. known failing checks;
7. mismatches between documentation and code;
8. founder/privacy/claims constraints relevant to the task.

Finish with a short proposed plan. Wait for implementation instructions.
