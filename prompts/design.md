# Design Task

Read `docs/NORTH_STAR.md`, `docs/BRAND.md`, `docs/DESIGN_SYSTEM.md`, and `docs/COPY_GUIDE.md`.

Design for:
- bold, not loud;
- serious with cultural warmth;
- accessible-first, premium in execution;
- deliberate texture;
- low-friction mobile use.

Avoid:
- generic SaaS minimalism;
- Uber-like disruption language;
- founder-as-brand;
- decorative motion that harms constrained devices.

Explain the visual rationale before large implementation changes.
