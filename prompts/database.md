# Database Change

Read `AGENTS.md`, `docs/DATABASE.md`, and `docs/SECURITY.md`.

For any schema proposal, first provide:
1. entity purpose;
2. fields;
3. data owner;
4. sensitivity;
5. retention assumption;
6. access roles;
7. migration plan;
8. rollback/data-loss risk.

Do not implement until the proposed model is coherent.

Never hand-edit generated migration output without explicit justification.
