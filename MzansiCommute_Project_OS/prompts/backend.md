# Backend / Data Task

Read `AGENTS.md`, `docs/DATABASE.md`, `docs/API.md`, and `docs/SECURITY.md`.

Before editing:
- describe the data boundary;
- identify personal/sensitive data;
- identify migration risk;
- confirm Cloudflare Worker compatibility.

Do not add new data collection merely because it may be useful later.

After editing:
- run schema generation if applicable;
- inspect migrations;
- run type/lint/test/build checks;
- report privacy/security implications.
