# Design System

This is a principle-level system. Exact tokens should remain aligned with the actual codebase and be updated when the visual system changes.

## Design intent

The interface should feel:
- bold without shouting;
- polished without becoming corporate-generic;
- rooted in South African taxi culture without becoming costume or cliché;
- information-dense where appropriate;
- legible on modest screens and networks.

## Layout

### Principle: rank-grid density
The design may use packed, structured composition rather than extreme whitespace.

Every visual "bay" should feel purposeful.

### Mobile first
Primary layouts should work on narrow screens before enhancement at larger breakpoints.

## Colour

The existing direction uses dark/high-contrast foundations with strong yellow/acid accents.

Rules:
- preserve readable contrast;
- do not use accent colour as a substitute for hierarchy;
- do not use low-contrast muted text for essential information;
- test states, forms, and disabled controls separately.

## Typography

- Strong display typography is appropriate for key messages.
- Body copy must remain highly readable.
- Avoid investor-deck jargon.
- Use South African English.

## Texture

Texture can come from:
- rank-inspired grids;
- route geometry;
- kinetic marquee bands;
- hand-signal or mobility references;
- dense operational-card layouts.

Avoid decorative texture that slows the site without adding identity.

## Motion

Motion should communicate:
- movement;
- route progression;
- activity.

Rules:
- all important content exists without motion;
- respect reduced-motion settings;
- heavy libraries must be gated behind the full performance tier;
- low-tier users get a complete static experience.

## Interaction

- obvious focus states;
- keyboard operability;
- touch-safe targets;
- no custom cursor on touch/coarse-pointer devices;
- forms must remain understandable without animation.

## Imagery

Avoid:
- generic stock images of smiling commuters;
- founder portraits;
- exoticised or poverty-framed representations of taxi culture.

Prefer:
- system diagrams;
- route abstractions;
- operational visuals;
- documentary imagery only when consent, attribution, and safety are clear.
