MzansiMove project guide
========================

Purpose
=======

Maintain a credible pre pilot website for MzansiMove and founder Ayanda Khoza.

Position the product as an operating layer for South African minibus taxi fleets.

Current facts
=============

The venture name is MzansiMove.

The intended pilot location is Makhanda in the Eastern Cape.

No pilot route has been confirmed.

All unverified traction must remain clearly labelled as a target or concept.

Working conventions
===================

Use South African English and locally grounded transport language.

Keep owner control and daily reconciliation as the primary value proposition.

Treat insurer reporting and data products as later stage capabilities.

Do not frame SARS as the primary customer or lead message.

Do not imply that the contact form delivers messages until a service is connected.

Build commands
==============

```bash
npm ci
npm run dev
npm run build
```

Important files
===============

app/page.tsx contains the page structure and content.

app/globals.css contains the responsive visual design.

app/layout.tsx contains metadata.

.openai/hosting.json contains Sites hosting configuration.
